# Workora

Your work. Your resources. Your context.

Workora is a personal productivity workspace designed
to help students and developers organize their work,
resources, notes and tasks in one place.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub

## Current Features

- Initial dashboard layout
- Sidebar navigation
- Continue Working section
- Reusable CSS design variables

## Project Structure

- css/: Styling
- js/: Application logic
- assets/: Images and icons

## Development Status

V0 - Foundation completed.
V1 - Workspace Management (upcoming).

## Future Plans

- Workspace management
- Resource manager
- Notes manager
- Task manager
- Recent activity tracking
